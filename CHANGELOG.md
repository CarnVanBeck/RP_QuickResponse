# Changelog

## 1.2.0

- Profiles ([#1](https://github.com/CarnVanBeck/RP_QuickResponse/issues/1)): share lines between characters.
  Create an account-wide profile in the settings, named after your character by default; it starts as a
  copy of your current lines. Every character can switch to any profile or keep its own lines.
  Each character keeps its own lines while it uses a profile, and its own button position.

## 1.1.0

- Every character now has its own categories and lines. Lines saved with 1.0.0 are not lost:
  each character starts with a copy of them on its first login, then changes them on its own.
- Every character now has its own button position and lock. Each character starts where the
  button was before; moving it on one character no longer moves it on the others.
  The minimap button stays the same for the whole account.

## 1.0.0

- A round, draggable button that opens your categories in a ring around it.
- Left-click a category for a random line, right-click it to pick one by its Short text.
- Lines run like your own macros: `/s`, `/e`, `/y`, emotes and any other command, several lines each.
- Works in combat.
- Settings window for categories and lines, with an icon browser searchable by name or file ID.
- Minimap button, AddOns menu entry and `/rpqr`.
- English and German.
